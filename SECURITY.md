# Security Policy

Personal Librarian is pre-1.0. Supported-version and security-update policies may
evolve as the project matures; reports concerning the current source and canonical
desktop release are welcome.

## Reporting a vulnerability

Prefer GitHub private vulnerability reporting when it is enabled for the repository.
If it is unavailable, use an appropriate private contact channel once one is listed by
the project owner. Do not open a public issue containing sensitive information.

Never attach or disclose private photos, videos, catalogue databases, credentials,
local filesystem paths, backup data, or other personal-library data. Provide only the
minimal reproduction steps and synthetic example data needed to demonstrate the issue.
