# M25 - Owner Usability Checklist

Allow approximately 10–20 minutes. Do not approve decisions or perform any destructive
action during this pass. Note observations in `M25_OWNER_USABILITY_FEEDBACK.md`.

- [ ] Verify the release ZIP checksum, extract it to a new folder, and launch
  `PersonalLibrarian.exe`.
- [ ] Choose or confirm the existing production application-data root and independent
  backup root.
- [ ] Confirm Overview loads and clearly reports production health and DR readiness.
- [ ] Browse several exact-duplicate groups and move between pages/groups using both
  controls and keyboard navigation.
- [ ] Open several real image previews; try Fit, 100%, zoom in/out, and mouse panning.
- [ ] Browse several similar-image groups and confirm they are visually and verbally
  distinct from exact duplicates.
- [ ] Inspect the Decisions section without recording a decision.
- [ ] Inspect Plans, Quarantine, and Backups / Recovery without executing anything.
- [ ] Resize the main window and adjust review panes; check for clipped or awkward text.
- [ ] Close and restart the application, then confirm harmless window/navigation
  preferences were retained.
- [ ] Record anything confusing, ugly, slow, missing, or misleading, including startup,
  navigation, preview, and decision-workflow concerns.
