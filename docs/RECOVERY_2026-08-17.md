## Incident

The former working drive Z: was a 4 TB SATA SSD identified by Windows as "SSD 4TB"; its machine serial is redacted from the public source tree.

During M5 OneDrive verification, Windows began returning repeated I/O failures including "A device which does not exist was specified".

Windows System events recorded:

- Disk Event ID 51: I/O errors on \Device\Harddisk0\DR0.
- NTFS Event ID 50: delayed-write failures, including Z:\$Mft and Z:\PersonalLibrarian\.git.
- NTFS Event ID 140: failure to flush the NTFS transaction log, with corruption possible.

Z: was therefore retired from active Personal Librarian use.
