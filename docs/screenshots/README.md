# Screenshot policy

There are no approved public screenshots yet. Future screenshots must use a purpose-built synthetic catalogue or content that has been explicitly sanitized for publication.

Screenshots must not reveal:

- private family photos, videos, documents, or library metadata;
- real catalogue, backup, inventory, or recovery data;
- usernames, personal filesystem paths, or application-data roots;
- device identifiers, volume serials, or machine names;
- private network addresses, server names, or share paths; or
- credentials, tokens, contact details, or other personal information.

Review both the visible interface and image metadata before adding a screenshot. Prefer small synthetic fixtures whose provenance and publication approval are clear.
